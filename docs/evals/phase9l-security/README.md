# Phase 9l injection defenses

46 corpus cases: 10 blocked structurally, 28 additional cases blocked after normalization and deterministic filtering, 38 cumulatively blocked. The independent raw filter blocks 29. Six benign and two semantic residual examples intentionally pass syntax checks. All eight remain excluded from prompts while proposed.

The corpus report contains case IDs, classifications, rule IDs and source hashes, never raw payloads or secret values. Human approval is an authorization gate; delimiting, output/readiness and kill-switch tests verify boundaries without claiming universal semantic attack detection. See D-60 for residual risks and the implementation log for actual verification counts.
